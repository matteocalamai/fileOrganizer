# File Organizer Utility

A fast, cross-platform command-line tool built in modern C++ to clean up messy directories automatically. 

## 🚀 Features
* **Smart Sorting:** Automatically detects file extensions (like `.png`, `.jpg`, `.gif`) and groups them into designated folders.
* **Modern C++:** Leverages the native `<filesystem>` library introduced in C++17 for optimal and safe performance.
* **Cross-Platform:** Designed to run seamlessly on macOS, Windows, and Linux.

## 📈 Future Improvements
* Add background monitoring (daemon mode) to sort incoming files in real-time.
